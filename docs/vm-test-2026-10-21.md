## Reproduction outline

Build the verified input ISO using the README command. Create two fresh disks with
`qemu-img create -f qcow2 target.qcow2 20G` and
`qemu-img create -f qcow2 control.qcow2 8G`. Run from their directory:

```sh
qemu-system-x86_64 -accel kvm -cpu host -m 3072 -smp 2 \
  -drive file=target.qcow2,format=qcow2,if=virtio \
  -drive file=control.qcow2,format=qcow2,if=virtio \
  -cdrom hamclock-amd64.iso -boot d \
  -nic user,model=virtio-net-pci,hostfwd=tcp:127.0.0.1:22222-:22
```

KVM device access is required. The recorded test used `-display none` with QMP
screen captures and key events instead of a GUI, and `-no-reboot` during install.
After installation, remove `-cdrom ...`, use `-boot c`, and boot the target. Never
replace the disposable file paths with host block-device paths.

## Remaining coverage

Still required: full UEFI installation, Secure Boot, real USB boot, iPXE installation,
existing-partition/LVM/RAID scenarios, firmware-dependent NIC/Wi-Fi hardware,
network-failure/recovery tests, and later HamClock/Comitup stages.
